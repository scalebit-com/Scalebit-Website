# Scalebit-Website

Welcome to the Scalebit AB website repository! This project contains the source code for the official website of Scalebit AB, a software engineering consultancy dedicated to helping businesses build scalable and robust solutions.

## About
Scalebit AB is a leading software engineering consultancy headquartered in Sweden. Our mission is to scale your digital potential by delivering expert solutions tailored to your business needs. This website serves as a platform to showcase our services, expertise, and contact information.

## Features
- **Responsive Design**: Optimized for all devices, from desktops to mobile phones.
- **Dark Mode**: Toggle between light and dark themes for better accessibility.
- **Smooth Navigation**: Includes smooth scrolling and active link highlighting.
- **Contact Form**: Easily get in touch with us through the integrated contact form.

## Technologies Used
- **HTML5**: For the structure of the website.
- **CSS3**: For styling, including responsive design and dark mode.
- **JavaScript**: For interactivity, such as theme toggling and form handling.
- **Google Fonts**: For modern and clean typography.
- **Font Awesome**: For icons used throughout the site.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/scalebit-website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd scalebit-website
   ```
3. Open `index.html` in your browser to view the website locally.
